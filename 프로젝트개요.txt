
ESP32 IOT 보드 활용 원격 제어보드

/RemoteDeck_PC : 아두이노로 구성된 펌웨어
/APITestUtility : 아두이노 보드와 API 연동 테스트 C# 응용프로그램
/IPSetupTool : ip등 환경설정 유틸리티 Windows 응용프로그램 (미구현)
/RemoteDeck_Hub : 여러대의 RemteDeck 운용 및 관리(미구현)


구성 
Server(Web page) - IPTV 세탑박스(안드로이드) - RemoteDeck_PC (rs485 연결) - TV (티비제어)
세탑박스에서 지원하지않는 티비 제어기능을 RemoteDeck 이 처리함.
