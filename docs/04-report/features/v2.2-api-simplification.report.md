## 2. 구현 내역

### 2.1 API 단순화 (Phase 1)

**Command (수신) — Before → After:**
```
Before: {"command":"RELAY","sequence":1,"data":1,"message":"null"}
After:  {"cmd":"relay","relay":1,"state":"on"}
```

**Status (발신) — Before → After:**
```
Before: {"device_id":"node_1","status":[{"type":"RELAY","sequence":1,"data":1}],"message":"null"}
After:  {"id":"node_1","event":"relay","relay1":1,"relay2":0}
```

**삭제된 파일 (4개):**
- `CommandConfig.h` — 직접 JSON 파싱으로 대체
- `StatusConfig.h` — 직접 JSON 빌드로 대체
- `JsonUtils.h/cpp` — 더 이상 불필요

**신규 이벤트 빌더 (main.cpp):**
- `buildOnlineEvent()` — 부팅/MQTT 연결 시
- `buildRelayEvent()` — 릴레이 상태 변경 시
- `buildPCLedEvent()` — PC 전원 변경 시
- `buildGPIOEvent()` — GPIO 변경 (향후 확장용)
- `buildFullEvent()` — status 명령 응답

### 2.2 Web Request (Phase 2)

**신규 파일:**
- `WebRequestHandler.h/cpp` — FreeRTOS task 기반 fire-and-forget HTTP GET

**12개 이벤트 × URL 설정:**
relay1_on/off, relay2_on/off, pcled_on/off, gpio1~3_high/low

**6개 플레이스홀더:**
`[device_id]`, `[device_name]`, `[ip]`, `[mac]`, `[event]`, `[value]`

**DeviceConfig 확장:**
- `WebRequestConfig` 구조체 추가
- `ConfigManager` 버퍼 2048→4096 확장

### 2.3 Web UI (Phase 3)

- 설정 탭에 **Web Request 서브탭** 추가 (5번째 탭)
- 이벤트별 URL 입력, enable/disable 토글, 저장

### 2.4 WebServer.cpp 버그 수정

- `/api/relay` 엔드포인트가 v2.2 `state` 필드를 인식하도록 수정
- 기존 `action` 필드도 하위 호환 유지

### 2.5 APITestUtility_v2 (추가 산출물)

- .NET 8 WinForms + MQTTnet + System.IO.Ports
- **4개 인터페이스 지원:** HTTP API, MQTT, WebSocket, RS485
- 인터페이스 선택 드롭다운으로 동일 명령을 다른 채널로 전송
- IO 상태 모니터: Relay1/2, PC-LED, GPIO1~3 실시간 표시
- Custom JSON 입력으로 자유로운 명령 전송

## 5. v2.2 API Reference

### Command (수신)

| cmd | 설명 | 필수 | 선택 |
|-----|------|------|------|
| `relay` | 릴레이 제어 | `relay`(1-2), `state`("on"/"off") | - |
| `pulse` | 릴레이 펄스 | `relay`(1-2) | `duration`(ms) |
| `status` | 전체 상태 요청 | - | - |
| `wol` | Wake-on-LAN | - | `mac` |
| `reboot` | 재부팅 | - | - |

### Status Event (발신)

| event | 발생 시점 | 필드 |
|-------|-----------|------|
| `online` | 부팅/MQTT 연결 | `id`, `ip`, `name`, `fw` |
| `relay` | 릴레이 변경 | `id`, `relay1`, `relay2` |
| `pcled` | PC 전원 변경 | `id`, `pc_on` |
| `full` | status 응답 | 모든 필드 |
