# RemoteDeck_PC 릴레이 배선 가이드

## 1. 릴레이 제원

**모델**: SONGLE SRD-05VDC-SL-C (x2)

| 항목 | 값 |
|------|-----|
| 코일 전압 | DC 5V |
| 접점 타입 | SPDT (COM / NO / NC) |
| AC 정격 | 10A @ 250VAC / 10A @ 125VAC |
| DC 정격 | 10A @ 30VDC / 10A @ 28VDC |
| 기계적 수명 | 10,000,000회 |
| 전기적 수명 | 100,000회 (정격 부하) |

### 접점 구성 (터미널 블록 기준)

```
┌─────────────────────────────┐
│  [COM]  [NO]  [NC]          │
│   ●      ●     ●            │
│   │      │     │            │
│   공통   평상시  평상시         │
│         열림    닫힘          │
└─────────────────────────────┘

릴레이 OFF 상태: COM ↔ NC 연결 (통전)
릴레이 ON 상태:  COM ↔ NO 연결 (통전)
```

## 2. Relay 1: PC 전원 스위치 (병렬 연결)

PC 케이스의 전원 버튼과 **병렬**로 연결하여, 물리 버튼과 원격 제어 모두 사용 가능하게 합니다.

### 2.1 F_PANEL 핀 배치

```
       +PWR_LED-    PWR_BTN
        ┌──┬──┐   ┌──┬──┐
        │ 1│ 2│   │ 3│ 4│
  PIN 1 ├──┼──┤   ├──┼──┤   NC
        │ 5│ 6│   │ 7│ 8│   ┌──┐
        └──┴──┘   └──┴──┘   │ 9│
       +HDD_LED-    RESET    └──┘
```

| 핀 | 기능 |
|----|------|
| 3 | PWR_BTN + (전원 버튼 +) |
| 4 | PWR_BTN - (전원 버튼 -) |

### 2.2 배선도

```
                          PC 메인보드
                          F_PANEL 헤더
                         ┌───────────┐
                         │  3    4   │
  기존 케이스 전원 버튼     │ PWR+ PWR- │
  ┌──────────────┐       └──┬────┬──┘
  │  PWR BUTTON  ├──────────┤    │      ← 기존 케이스 버튼 (그대로 유지)
  └──────────────┘          │    │
                            │    │
  RemoteDeck Relay 1        │    │
  ┌──────────────┐          │    │
  │   COM ───────┼──────────┘    │
  │    NO ───────┼───────────────┘
  │    NC        │ (사용 안함)
  └──────────────┘
```

### 2.3 연결 순서

1. PC 케이스를 열고 메인보드 F_PANEL 헤더에서 **PWR_BTN** 커넥터를 확인 (핀 3, 4)
2. 기존 케이스 전원 버튼 케이블은 **그대로 연결 유지**
3. RemoteDeck Relay 1의 **COM** → F_PANEL 핀 3 (PWR_BTN +)
4. RemoteDeck Relay 1의 **NO** → F_PANEL 핀 4 (PWR_BTN -)
5. 분기 커넥터 또는 점퍼 와이어로 병렬 연결

### 2.4 동작 원리

| 동작 | 설명 |
|------|------|
| **Pulse (500ms)** | 릴레이가 0.5초간 ON → OFF = 전원 버튼 짧게 누름 = **PC 켜기/끄기** |
| **Pulse (5000ms)** | 릴레이가 5초간 ON → OFF = 전원 버튼 길게 누름 = **강제 종료** |

> **주의**: PWR_BTN은 단순 단락(short) 신호입니다. 극성이 없으므로 COM/NO를 어느 쪽에 연결해도 동작합니다.

## 3. Relay 2: 220V 기기 제어 (조명, 빔프로젝터 등)

릴레이 자체는 250VAC/10A를 지원하지만, **안전을 위해 220V를 직접 연결하지 않고** Dry Contact 방식으로 외부 전원 제어 장치를 트리거합니다.

### 3.1 방법 A: 스마트 플러그의 물리 버튼 병렬 연결

기존 스마트 플러그(Wi-Fi 콘센트)의 **물리 ON/OFF 버튼**에 Relay 2를 병렬 연결합니다.

```
  RemoteDeck Relay 2
  ┌──────────────┐        스마트 플러그 내부
  │   COM ───────┼────── 버튼 한쪽 ──┐
  │    NO ───────┼────── 버튼 반대쪽 ─┤
  │    NC        │                   │
  └──────────────┘        ┌──────────┴──────────┐
                          │   Smart Plug MCU     │
                          │   (버튼 입력 감지)      │
                          │   → 220V 릴레이 제어   │
                          └─────────────────────┘
                                    │
                              ┌─────┴─────┐
                              │  220V 기기  │
                              │ (조명, 빔)   │
                              └───────────┘
```

**장점**: 220V 배선 불필요, 스마트 플러그가 220V 차단/안전 담당
**단점**: 스마트 플러그 분해 필요, 토글 방식이라 현재 상태 확인 필요

### 3.2 방법 B: SSR (Solid State Relay) 연동

Dry Contact로 SSR을 트리거하여 220V를 제어합니다.

```
  RemoteDeck Relay 2          SSR (Solid State Relay)
  ┌──────────────┐          ┌───────────────────────┐
  │   COM ───────┼── DC+ ──┤ 입력 + (3~32VDC)       │
  │    NO ───────┼── DC- ──┤ 입력 - (3~32VDC)       │
  │    NC        │          │                       │
  └──────────────┘          │ 출력 L ────── 220V L ──┼── 기기
         │                  │ 출력 N ────── 220V N ──┼── (조명/빔)
    DC 5V 전원              └───────────────────────┘
    (RemoteDeck 보드
     또는 외부 5V)

  SSR 입력에 DC 5V 인가 → SSR 출력 220V 통전
```

**추천 SSR 모델:**

| 모델 | 입력 | 출력 | 가격대 |
|------|------|------|--------|
| Fotek SSR-25DA | 3~32VDC | 24~380VAC / 25A | 5,000~8,000원 |
| Fotek SSR-40DA | 3~32VDC | 24~380VAC / 40A | 8,000~12,000원 |
| Omron G3MB-202P | 5VDC | 240VAC / 2A | 2,000~3,000원 (소용량) |

**배선 상세:**

```
  RemoteDeck 보드                 SSR-25DA
  ┌────────────┐                ┌──────────┐
  │ 5V (보드전원) ├──── COM ──────┤ DC+  (3) │
  │            │                │          │         ┌────────┐
  │ Relay2 NO  ├────────────────┤ DC-  (4) │    L ───┤        │
  │            │                │          ├─────────┤ 220V   │
  │            │         N ─────┤ AC1  (1) │    N ───┤ 기기    │
  │            │                │          │         └────────┘
  │            │     220V L ────┤ AC2  (2) │
  └────────────┘                └──────────┘
```

> **주의**: SSR에는 방열판 필수 (10A 이상 부하 시). 소용량(2A 이하)은 방열판 불필요.

### 3.3 방법 C: 전자식 접촉기 (Magnetic Contactor) 연동

대용량(1kW 이상) 기기 제어 시 접촉기를 사용합니다.

```
  RemoteDeck Relay 2          전자 접촉기 (MC)
  ┌──────────────┐          ┌──────────────────┐
  │   COM ───────┼── A1 ───┤ 코일 A1 (220V L)   │
  │    NO ───────┼── A2 ───┤ 코일 A2 (220V N)   │
  │    NC        │          │                  │
  └──────────────┘          │ 주접점:            │
                            │  L ──── 기기 L    │
                            │  N ──── 기기 N    │
                            └──────────────────┘

  ※ 이 방식은 릴레이가 접촉기 코일(220V)을 직접 스위칭합니다.
     SRD-05VDC-SL-C는 250VAC/10A 지원이므로 가능하지만,
     코일 전류가 작으므로 (보통 30~50mA) 안전합니다.
```

### 3.4 방법 비교

| 방법 | 220V 직접 배선 | 추가 부품 | 난이도 | 추천 용도 |
|------|:-------------:|----------|:------:|----------|
| **A. 스마트 플러그** | X | 스마트 플러그 | 하 | 간단한 조명 1~2개 |
| **B. SSR** | O (SSR 출력측) | SSR + 방열판 | 중 | 조명, 빔프로젝터 (10A 이하) |
| **C. 접촉기** | O (코일/주접점) | 전자 접촉기 | 상 | 대용량 기기 (1kW 이상) |

> **권장**: 일반 조명/빔프로젝터는 **방법 B (SSR)** 추천. 추가 배선 최소화하려면 **방법 A (스마트 플러그)**.

## 4. 안전 주의사항

1. **220V 작업 시 반드시 차단기를 내리고 작업**할 것
2. SSR/접촉기 사용 시 **적절한 용량 선정** (기기 소비전력의 1.5배 이상)
3. SSR 10A 이상 부하 시 **방열판 필수**
4. 모든 배선은 **절연 처리** (열수축 튜브 또는 절연 테이프)
5. PC 전원 스위치 배선은 **저전압 (3.3V)** 이므로 감전 위험 없음
6. Relay 2로 220V를 직접 스위칭하는 것은 릴레이 사양상 가능하나, **안전 인증 없는 기판에서는 권장하지 않음**

## 5. 구매 목록 (방법 B 기준)

| 품목 | 수량 | 참고 |
|------|:----:|------|
| 점퍼 와이어 (듀폰 케이블 암-암) | 2개 | Relay 1 → F_PANEL 연결 |
| SSR-25DA (또는 SSR-10DA) | 1개 | Relay 2 → 220V 기기 제어 |
| 방열판 (SSR용) | 1개 | 10A 이상 부하 시 |
| 배선용 전선 (1.5sq) | 적정 | 220V 구간 |
| 절연 단자 / 열수축 튜브 | 적정 | 안전 처리 |
