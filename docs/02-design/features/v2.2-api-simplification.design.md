# v2.2 API 단순화 Design Document

> **Summary**: RS485/MQTT 명령 체계를 직관적 평문 JSON으로 재설계하고, IO 상태 변경 시 HTTP GET 호출하는 Web Request 기능 추가
>
> **Project**: RemoteDeck_PC (원격 PC 전원관리)
> **Version**: v2.2.0
> **Author**: KDI
> **Date**: 2026-04-10
> **Status**: Draft
> **Planning Doc**: [v2.2-api-simplification.plan.md](../../01-plan/features/v2.2-api-simplification.plan.md)

---

## 1. Overview

### 1.1 Design Goals

1. Command/Status JSON 구조를 중첩 배열 없이 1-depth 평문으로 단순화
2. CommandConfig/StatusConfig 클래스를 제거하고 직접 JSON 빌드/파싱으로 전환
3. MQTTHandler가 String payload를 직접 publish하도록 단순화
4. WebRequestHandler 신규 모듈: FreeRTOS task 기반 fire-and-forget HTTP GET
5. Web UI에 Web Request 서브탭 추가

### 1.2 Design Principles

- **단순성**: 모든 JSON payload가 `{}` 1-depth, 배열 없음
- **비파괴성**: WebSocket 대시보드(buildStatusJson)는 기존 그대로 유지 (내부용)
- **비블로킹**: Web Request HTTP 호출은 FreeRTOS task로 main loop 분리
- **하위호환**: deviceconfig.json에 web_request 키 없으면 기능 비활성

## 2. Architecture

### 2.1 Component Diagram

```
┌─────────────┐  cmd JSON  ┌──────────────┐  cmd JSON  ┌──────────────┐
│  MQTT Sub   │───────────▶│              │◀───────────│  RS485 RX    │
│ (topic_sub) │            │   main.cpp   │            │ (Serial2)    │
└─────────────┘            │ processCmd() │            └──────────────┘
                           │              │
                           │  상태 변경    │
                           │      │       │
                    ┌──────┴──────┼───────┴──────┐
                    ▼             ▼              ▼
            ┌────────────┐ ┌──────────┐  ┌──────────────┐
            │ MQTT Pub   │ │ RS485 TX │  │ WebRequest   │ ← 신규
            │(topic_pub) │ │(Serial2) │  │ Handler      │
            │ String pub │ │ String   │  │ HTTP GET     │
            └────────────┘ └──────────┘  │ (FreeRTOS)   │
                                         └──────────────┘
                    │             │              │
              status JSON   status JSON    HTTP GET call
              (평문)        (평문)         (fire-and-forget)
```

### 2.2 Data Flow

**Command 수신:**
```
MQTT/RS485 raw JSON → deserializeJson(직접) → processCommand(cmd, relay, state, ...)
```

**Status 발신:**
```
IO 변경 → buildEventJson(event, ...) → MQTT publish(String)
                                      → RS485 send(String)
                                      → WebRequest fire(event, value)
```

### 2.3 Dependencies

| Component | Depends On | Purpose |
|-----------|-----------|---------|
| main.cpp processCommand() | ArduinoJson | 직접 JSON 파싱 |
| main.cpp buildEventJson() | ArduinoJson | 직접 JSON 빌드 |
| MQTTHandler.publish() | PubSubClient | String payload 전송 |
| WebRequestHandler | HTTPClient, FreeRTOS | 비동기 HTTP GET |
| ConfigManager | ArduinoJson, SPIFFS | web_request 설정 로드/저장 |

**Before:**

```cpp
        relayController.setRelay(cmd.sequence, cmd.data == 1);
    } else if (cmd.command == "PULSE") {
        uint16_t duration = cmd.data > 0 ? cmd.data : config.relay.pulseShortMs;
        relayController.pulse(cmd.sequence, duration);
    }
    // ...
}
```

**After:**
```cpp
void onMQTTCommand(const char* payload, unsigned int length) {
    processCommand(payload, "MQTT");
}

void onRS485Command(const char* json) {
    processCommand(json, "RS485");
}

void processCommand(const char* json, const char* source) {
    StaticJsonDocument<256> doc;
    if (deserializeJson(doc, json)) {
        Serial.printf("CMD parse error from %s\n", source);
        return;
    }

    const char* cmd = doc["cmd"] | "";
    logger.log("CMD", (String(cmd) + " from " + source).c_str());

    if (strcmp(cmd, "relay") == 0) {
        uint8_t relay = doc["relay"] | 1;
        const char* state = doc["state"] | "on";
        relayController.setRelay(relay, strcmp(state, "on") == 0);

    } else if (strcmp(cmd, "pulse") == 0) {
        uint8_t relay = doc["relay"] | 1;
        uint16_t duration = doc["duration"] | config.relay.pulseShortMs;
        relayController.pulse(relay, duration);

    } else if (strcmp(cmd, "status") == 0) {
        sendFullStatus();

    } else if (strcmp(cmd, "wol") == 0) {
        const char* mac = doc["mac"] | "";
        if (strlen(mac) > 0) wolSender.send(mac);
        else wolSender.sendDefault();

    } else if (strcmp(cmd, "reboot") == 0) {
        logger.log("REBOOT", source);
        delay(1000);
        ESP.restart();
    }
}
```

```cpp
// 이벤트별 JSON 빌드 함수
String buildRelayEvent() {
    StaticJsonDocument<128> doc;
    doc["id"] = config.deviceId;
    doc["event"] = "relay";
    doc["relay1"] = relayController.getRelay(1) ? 1 : 0;
    doc["relay2"] = relayController.getRelay(2) ? 1 : 0;
    String out; serializeJson(doc, out); return out;
}

String buildPCLedEvent() {
    StaticJsonDocument<128> doc;
    doc["id"] = config.deviceId;
    doc["event"] = "pcled";
    doc["pc_on"] = pcMonitor.isPCOn();
    String out; serializeJson(doc, out); return out;
}

String buildOnlineEvent() {
    StaticJsonDocument<256> doc;
    doc["id"] = config.deviceId;
    doc["event"] = "online";
    doc["ip"] = networkManager.localIP().toString();
    doc["name"] = config.deviceName;
    doc["fw"] = config.firmware.version;
    String out; serializeJson(doc, out); return out;
}

String buildFullEvent() {
    StaticJsonDocument<512> doc;
    doc["id"] = config.deviceId;
    doc["event"] = "full";
    doc["ip"] = networkManager.localIP().toString();
    doc["name"] = config.deviceName;
    doc["fw"] = config.firmware.version;
    doc["relay1"] = relayController.getRelay(1) ? 1 : 0;
    doc["relay2"] = relayController.getRelay(2) ? 1 : 0;
    doc["pc_on"] = pcMonitor.isPCOn();
    doc["gpio1"] = digitalRead(PIN_GPIO1);
    doc["gpio2"] = digitalRead(PIN_GPIO2);
    doc["gpio3"] = digitalRead(PIN_GPIO3);
    doc["uptime"] = ntpSync.getUptime();
    doc["mqtt"] = mqttHandler.isConnected();
    String out; serializeJson(doc, out); return out;
}

// 통합 발신 함수
void publishEvent(const String& json) {
    mqttHandler.publish(json.c_str());
    rs485Handler.send(json.c_str());
}

// 콜백 변경
void onRelayChange(uint8_t relay, bool state) {
    logger.log("RELAY", (String("Relay") + relay + (state ? " ON" : " OFF")).c_str());
    String json = buildRelayEvent();
    publishEvent(json);
    webServer.ws().broadcastStatus(buildStatusJson().c_str()); // WebSocket은 기존 유지
    // Web Request
    if (relay == 1) webRequestHandler.fire(state ? "relay1_on" : "relay1_off", state ? 1 : 0);
    else            webRequestHandler.fire(state ? "relay2_on" : "relay2_off", state ? 1 : 0);
}

void onPCStateChange(bool pcOn) {
    logger.log("PCLED", pcOn ? "PC ON" : "PC OFF");
    String json = buildPCLedEvent();
    publishEvent(json);
    webServer.ws().broadcastStatus(buildStatusJson().c_str());
    webRequestHandler.fire(pcOn ? "pcled_on" : "pcled_off", pcOn ? 1 : 0);
}

void sendFullStatus() {
    String json = buildFullEvent();
    publishEvent(json);
}
```

### 4.3 신규 파일

#### 4.3.1 `src/network/WebRequestHandler.h`

```cpp
#pragma once
#include <Arduino.h>
#include <functional>
#include "config/DeviceConfig.h"

class WebRequestHandler {
public:
    void begin(const WebRequestConfig* config, const DeviceConfig* deviceConfig);
    void fire(const char* event, int value);

private:
    const WebRequestConfig* _config = nullptr;
    const DeviceConfig* _deviceConfig = nullptr;

    // FreeRTOS task 중복 방지
    volatile bool _busy = false;

    String getURL(const char* event) const;
    String replacePlaceholders(const String& url, const char* event, int value) const;

    // FreeRTOS task로 실행
    struct RequestParams {
        char url[256];
        uint16_t timeoutMs;
        volatile bool* busyFlag;
    };
    static void httpGetTask(void* param);
};
```

#### 4.3.2 `src/network/WebRequestHandler.cpp`

```cpp
#include "WebRequestHandler.h"
#include <HTTPClient.h>
#include <WiFi.h>

void WebRequestHandler::begin(const WebRequestConfig* config, const DeviceConfig* deviceConfig) {
    _config = config;
    _deviceConfig = deviceConfig;
}

void WebRequestHandler::fire(const char* event, int value) {
    if (!_config || !_config->enabled) return;
    if (_busy) return;  // 이전 요청 진행 중이면 스킵

    String url = getURL(event);
    if (url.isEmpty()) return;

    url = replacePlaceholders(url, event, value);

    // FreeRTOS task로 비동기 실행
    auto* params = new RequestParams();
    strlcpy(params->url, url.c_str(), sizeof(params->url));
    params->timeoutMs = _config->timeoutMs;
    params->busyFlag = &_busy;
    _busy = true;

    xTaskCreate(httpGetTask, "webReq", 8192, params, 1, NULL);
}

String WebRequestHandler::getURL(const char* event) const {
    if (strcmp(event, "relay1_on") == 0)  return String(_config->relay1_on.c_str());
    if (strcmp(event, "relay1_off") == 0) return String(_config->relay1_off.c_str());
    if (strcmp(event, "relay2_on") == 0)  return String(_config->relay2_on.c_str());
    if (strcmp(event, "relay2_off") == 0) return String(_config->relay2_off.c_str());
    if (strcmp(event, "pcled_on") == 0)   return String(_config->pcled_on.c_str());
    if (strcmp(event, "pcled_off") == 0)  return String(_config->pcled_off.c_str());
    if (strcmp(event, "gpio1_high") == 0) return String(_config->gpio1_high.c_str());
    if (strcmp(event, "gpio1_low") == 0)  return String(_config->gpio1_low.c_str());
    if (strcmp(event, "gpio2_high") == 0) return String(_config->gpio2_high.c_str());
    if (strcmp(event, "gpio2_low") == 0)  return String(_config->gpio2_low.c_str());
    if (strcmp(event, "gpio3_high") == 0) return String(_config->gpio3_high.c_str());
    if (strcmp(event, "gpio3_low") == 0)  return String(_config->gpio3_low.c_str());
    return "";
}

String WebRequestHandler::replacePlaceholders(const String& url, const char* event, int value) const {
    String result = url;
    result.replace("[device_id]", _deviceConfig->deviceId.c_str());
    result.replace("[device_name]", _deviceConfig->deviceName.c_str());
    result.replace("[ip]", /* networkManager IP - passed via deviceConfig or getter */);
    result.replace("[mac]", /* MAC address */);
    result.replace("[event]", event);
    result.replace("[value]", String(value));
    return result;
}

void WebRequestHandler::httpGetTask(void* param) {
    auto* p = (RequestParams*)param;
    HTTPClient http;
    http.setTimeout(p->timeoutMs);
    http.begin(p->url);
    int code = http.GET();
    Serial.printf("WebRequest [%d]: %s\n", code, p->url);
    http.end();
    *(p->busyFlag) = false;
    delete p;
    vTaskDelete(NULL);
}
```

> **Note**: `replacePlaceholders()`의 `[ip]`/`[mac]` 치환을 위해 WebRequestHandler에 IP/MAC getter 콜백을 추가하거나, fire() 호출 시 ip/mac을 파라미터로 전달.

## 5. Security Considerations

- [x] Web Request URL은 SPIFFS에 평문 저장 (ESP32 물리 접근 제한 전제)
- [x] Web Request는 HTTP only (HTTPS는 ESP32 메모리 제약으로 미지원)
- [x] URL 최대 길이 256자 제한 (buffer overflow 방지)
- [x] Basic Auth는 기존 그대로 유지 (Web UI, API 모두)
