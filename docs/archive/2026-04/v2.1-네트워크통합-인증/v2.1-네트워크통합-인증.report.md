## Implementation Results

### 펌웨어 v2.1

| 변경 | v2.0 | v2.1 |
|------|------|------|
| **네트워크** | Ethernet2 + WiFi AP | ETH.h + WiFi STA (단일 lwIP) |
| **WiFi 모드** | AP만 (핫스팟) | STA (기존 네트워크 연결) |
| **듀얼 네트워크** | 없음 | WiFi 모드에서 ETH 관리 192.168.1.200 동시 가동 |
| **Web UI 접근** | WiFi AP에서만 | Ethernet/WiFi 모두 해당 IP:5050 |
| **인증** | 없음 | Basic Auth (전체 Web UI) |
| **계정 변경** | 없음 | Web UI + UDP CHANGE_AUTH |
| **장치 이름** | 없음 | deviceName (기본: 새기기) |
| **Ethernet2** | lib/Ethernet2/ (패치) | 삭제 (ETH.h 대체) |
| **RAM** | 15.8% | 15.9% (+24 bytes) |
| **Flash** | 63.2% | 64.0% (+14KB) |

### IPSetupTool v2.1

| 변경 | v2.0 | v2.1 |
|------|------|------|
| **네트워크 모드** | ethernet 고정 | 드롭다운: ethernet / wifi |
| **WiFi 설정** | SSID/PW만 | SSID/PW + IP/GW/Subnet/DNS + DHCP |

| **WiFi 모드 접속** | 불가 | ETH 관리 IP 자동 접속 |
| **웹 UI 열기** | WiFi AP 안내 | 기기 IP 직접 브라우저 열기 |

## Issues Resolved

| # | Issue | Root Cause | Resolution |
|---|-------|-----------|------------|
| 1 | WiFi STA 연결 실패 | `WiFi.config()` 순서 (begin 전 호출) | begin 후 config 호출로 변경 |
| 2 | WiFi IP 필드 저장 안 됨 | onUDPConfig에서 wifi ip/gw/sn/dns 미처리 | 4개 필드 저장 추가 |
| 3 | 숨겨진 SSID 연결 불가 | WiFi.begin() 기본 설정 | hidden SSID 스캔 활성화 |
| 4 | WiFi 모드에서 IPSetupTool 접근 불가 | WiFi IP로만 서비스 | ETH 관리 192.168.1.200 동시 가동 |
| 5 | DISCOVER_ACK에서 0.0.0.0 리턴 | WiFi 미연결 시 WiFi.localIP() | ETH IP 폴백 |
| 6 | WiFi disconnect 로그 스팸 | 매 이벤트 로깅 | 5초 간격 + reason 코드 |
